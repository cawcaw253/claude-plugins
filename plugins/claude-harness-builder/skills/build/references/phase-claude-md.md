## Merge strategy when CLAUDE.md exists

NEVER rewrite, reorder, or dedupe existing user content. Append-only, under a
marker:

1. Read the existing file; look for
   `<!-- harness-builder:begin -->` … `<!-- harness-builder:end -->`.
2. Marker absent → append at end of file:
   ```
   <!-- harness-builder:begin (generated by /claude-harness-builder:build — edits inside this block may be overwritten on re-run) -->
   ...generated sections...
   <!-- harness-builder:end -->
   ```
3. Marker present (re-run) → single-select: "Replace generated block / Append
   new sections inside the block / Skip". Replace touches ONLY the text
   between markers.
4. If an existing user-authored heading already covers a selected section
   (case-insensitive match on "commit", "convention", "command"), do NOT
   duplicate it — add one line inside the generated block:
   `See the existing "<heading>" section above; not regenerated.`
5. Show the full text to be appended (new content, so full text — not a
   diff), confirm Apply / Edit first / Skip, write, record in state
   `appliedFiles`.
